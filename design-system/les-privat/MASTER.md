# Les Privat — antarmuka awal

Keputusan implementer untuk tampilan awal, bukan keputusan merek final pengguna. Rujukan: hasil ui-ux-pro-max untuk `education tutoring light dashboard`; hasil awal bergaya terminal gelap ditolak karena tidak cocok untuk guru les.

- Gaya minimal dan terang, halaman ringkas dengan hierarki judul jelas; tata letak ponsel lebih dahulu.
- Warna utama teal gelap `#0f766e` dengan teks putih; latar `#f7faf9`, permukaan putih, teks `#17332f`, teks sekunder `#526761`. Kontras pasangan harus diperiksa pada hasil akhir.
- Aksen amber dipakai sebagai penanda, bukan satu-satunya cara menyampaikan status.
- Font sistem sans-serif untuk menghindari ketergantungan unduhan font. Angka memakai tabular numerals.
- Tombol minimal 44 piksel, label formulir terlihat, fokus keyboard jelas, pesan gagal dekat formulir, pending/sukses dibedakan.
- Ikon Lucide; tanpa emoji sebagai ikon. Gerakan hanya transisi singkat dan mengikuti reduced motion.
- Konten berbahasa Indonesia. Tidak menampilkan angka pengguna, testimoni, rating, atau statistik pemasaran rekaan.
- Data contoh diberi label; tidak dicampurkan dengan catatan nyata.
